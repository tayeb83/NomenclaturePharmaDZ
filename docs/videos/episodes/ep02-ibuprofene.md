## Notes de production
- Le thésaurus ANSM traite les AINS **par classe** : montrer dans l'outil la ligne « Classe ANTI-INFLAMMATOIRES… » (c'est ce que l'onglet Interactions affiche), pas une interaction « ibuprofène » inventée.
- Varicelle : ne pas l'évoquer ici (nuance à relire avec le pharmacien) ; la garder pour un épisode « enfants ».
