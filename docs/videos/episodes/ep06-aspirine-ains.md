## Notes de production
- Ne jamais écrire « aspirine = dangereux ». Le message est « la dose et l'association comptent ».
- Les lignes ANSM de l'aspirine sont nombreuses (17) : n'en montrer que 3 à l'écran, les mêmes que dans le script.
